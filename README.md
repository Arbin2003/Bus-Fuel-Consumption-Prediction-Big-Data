# Bus Fuel Consumption Prediction using Big Data and Machine Learning

## Project Overview

This project develops a machine learning-based system to predict bus fuel consumption using operational and environmental data. The project was implemented using PySpark for big data processing, Random Forest Regression for prediction, and Streamlit for interactive deployment.

## Technologies Used

- Python
- PySpark
- Random Forest Regression
- Streamlit
- Pandas
- Matplotlib

## Project Structure

- app/ → Streamlit dashboard
- notebooks/ → Data processing and machine learning
- data/ → Dataset
- images/ → Figures and screenshots
- report/ → Final project report

## Machine Learning Models

- Linear Regression
- Decision Tree Regression
- Random Forest Regression (Best Model)

## Best Model Performance

- R² Score: 0.9969
- MAE: 16.15
- RMSE: 46.34

## Dashboard

The Streamlit dashboard allows users to enter journey information and receive fuel consumption predictions through an interactive interface.
